# Homebrew tap

```bash
brew install --cask kriswonka/tap/fanshift
```

| Cask | What it is |
|---|---|
| [fanshift](Casks/fanshift.rb) | [FanShift](https://github.com/KrisWonka/FanShift): menu bar fan control for Apple silicon Macs, with a global hotkey and custom fan curves |

Update with `brew upgrade --cask fanshift`.
